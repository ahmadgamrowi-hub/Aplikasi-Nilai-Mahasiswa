# APLIKASI NILAI MAHASISWA

## Deskripsi
Aplikasi Nilai Mahasiswa adalah program Python
untuk mengelola data mahasiswa dan menghitung
nilai akhir berdasarkan tugas, UTS, dan UAS.

## Fitur
1. Menambah data mahasiswa
2. Menampilkan data mahasiswa
3. Mencari mahasiswa
4. Mengubah nilai mahasiswa
5. Menghapus data mahasiswa
6. Menentukan grade dan kelulusan

## Materi OOP
- Class dan Object
- Constructor
- Encapsulation
- Inheritance
- Polymorphism
- Method
- Property

## Rumus Nilai
Nilai Akhir =
(Tugas x 30%) + (UTS x 30%) + (UAS x 40%)

## Bahasa Pemrograman
Python

## Cara Menjalankan
1. Buka folder project di VS Code.
2. Buka file main.py.
3. Jalankan program menggunakan Python.

## Kesimpulan
Project ini dibuat untuk menerapkan
konsep Object Oriented Programming (OOP)
dalam aplikasi pengolahan nilai mahasiswa.
